# Colorectal histopathology classification

Two projects with equivalent commands for dataset, training, evaluation, prediction and inspection: [PolyGabor](polygarbor/README.md), based on texture/color descriptors and polynomial subspaces, and [CNN](cnn/README.md), with ResNet-18 and YOLO11n converted from the notebook and random/ImageNet initialization controls.

The [experimental comparison](comparison/README.md) records shared splits, generalization across sources, few-shot training, augmentations, patch grids, adverse conditions, quantitative localization in mosaics, CPU/GPU, memory, model size and inference under resource constraints. See the [discussion and visual assessment](comparison/results/2026-09-12/DISCUSSION.md), the [report](comparison/results/2026-09-12/REPORT.md), the [localization test](comparison/results/2026-09-12/localization/README.md), the [curves and tables](comparison/results/2026-09-12/) and the [explanation of G-mean versus macro-F1](comparison/GMEAN_VS_MACRO_F1.md).

The notebooks `cnn_test.ipynb` and `garbor-downsampling.ipynb` were used for exploratory tests on a remote GPU server, which is why their outputs show paths from that environment. All reported experiments were run with the Python versions in this repository (`cnn/`, `polygarbor/` and `comparison/`). Large models and data stay on disk and are ignored by Git; configurations, logs, metrics and figures make it possible to audit every run.
